## 什么**不**在这里

**历史审计报告全部删除了。** 原因是它们审的对象不在本仓：

- 8 份审 `dsh-plugin-process-lab`（另一个仓，已归档）
- 2 份审 `.dsh/skills/plugin-kit/`（本仓的旧开发树，已删）
- 3 份是本仓的过期快照（`@007ace2` 时代，落后几十个提交）

**保留它们不是「留个记录」，是制造误导**：读者点进去会看到 400 行讲着另一个仓的数字，而正文里的旧语义（阶段门会拦人）已经在 2026-11-11 被推翻。

删除的那批文件里，有 78 处引用了本仓不存在的文件名——它们本来就已经断了。
