# 需求：dsh-draft-studio（草稿工坊）

> 一句话：把输入框里写到一半的草稿，一键原地改写成 AI 真能照着干的提示词——不发送、不弹窗、不换页面，一键可还原。

## 功能

1. **按钮**：草稿非空时出现在发送键左侧；最多四颗，每颗对应一套预设（通用 / 编程 / 写作 / 翻译）。
2. **改写**：拿草稿（可选带会话最近几轮，消解「刚才说的」这类指代）发给模型，只返回改写文本，写回输入框。
3. **不替用户拍板**：草稿里没决定的事（如技术栈）列成候选，不替选。
4. **四态按钮**：空闲 / 运行中（可取消，显示已用秒数）/ 可回退 / 失败（悬停看原因，可重试）。一颗在跑，其余置灰；回退和重试只作用于自己那次。
5. **并发宽容**：等待期间可以继续打字、切会话、直接发送——结果**不覆盖新输入**，保留待重试；切走再切回请求不断；发送后转圈自停。
6. **设置页**：总开关 / 读上下文开关 / 预设编辑（编辑门防误改；就地改名 ≤12 字；恢复内置默认）/ 显示哪几颗按钮（取消勾选不丢预设）/ 模型来源（跟随会话含强度，或固定模型+强度）/ 上次改写回显（读了几轮几字，或没读的原因）/ 未保存计数 + 保存/放弃。
7. 约 20 个配置项可改，**改完即时生效**（每次请求重读）。

## 边界 / 非目标

- 含 `/` 命令芯片的草稿可能写不回——原稿不丢，结果保留待重试；`@` 引用不受影响；手打的 `/xxx` 是普通文字。
- 固定模型不支持所选思考强度时，自动按该模型默认强度重试。
- 超时上限约 8 分钟；超时后草稿不变，可重试。
- **不做**：自动发送、多轮改写、模板库、历史记录、重启后上下文回放。
- 设置服务不可用时降级：退回一颗按钮、请求不带预设 id，行为不报错（设计兜底，不是故障）。

## 验收标准（行为版）

1. 点按钮 → 输入框内容被替换为改写稿；回退（或 Ctrl+Z）还原原文。
2. 全程不发送消息。
3. 四套预设各自生效；隐藏的按钮不出现，重新勾选即回来；改名只影响显示。
4. 跟随模式用当前会话的模型与强度；固定模式用固定值。
5. 一颗运行时其余不可点；结果绝不覆盖等待期间的新输入。
6. 草稿为空时无按钮。
