# 需求：dsh-enhance

> 一句话：模型不变，换的是它每轮开局读到的那份系统提示——开头那句品牌声明可以换成你的，末尾可以追加一段你自己写的内容边界。

## 功能

1. **品牌人设三态**：保留 / 去掉开头那句 / 换成自定义文本（≤2KB，首次保存时创建）。
2. **内容边界**：一段 ≤8KB 的文本，接在每条系统提示的末尾。
3. **越界审批三态**：动作超出当前档位时——自动放行 / 先问我 / 自动回绝。
4. **Enhanced 权限档（可选）**：新增一个「沙箱全开、越界仍先问」的档位。写档是**唯一**碰宿主配置的动作，只在用户点按钮时发生；档位表必须写全（宿主配置是整块替换不是合并，只写新档会抹掉内置档）；每次写档留时间戳 `.bak`；不改用户默认档。
5. **五个开关**（存状态文件）：总开关 / 内容边界 / 越界审批 / 品牌人设 / 隐藏宿主说明。布尔值认字符串；**状态文件损坏不静默放行**——审批回落「先问我」，人设回落「保留」。「隐藏宿主说明」有代价：连同操作约定一起消失，要在界面上讲清。
6. **设置页**：五组对应以上；页面写的和手改的文件始终是同一份；人设改动下一条消息生效、不用重启。
7. **检查**：读回会话日志，证明写的东西真的进了提示词；没生效就明说「未生效」，不糊弄。
8. 存盘即生效；不改宿主文件；随时一键退回。

## 边界 / 非目标

- 默认设置下，宿主自指的注册项一个不动；只有改了身份三态或开了隐藏才顶掉对应项。
- 卸载后用户写的文本和开关**保留**；从旧包名（无 scope）装过的用户需先卸旧再装新（迁移说明）。
- 兼容立场：**不声明宿主版本要求**；升级后靠体检确认存活。

## 验收标准（行为版）

1. 全部开关关闭时，系统提示与宿主原样一致。
2. 人设 + 内容边界都写好后，下一条消息的系统提示：开头句已替换、末尾已追加，且「检查」能证实。
3. allow / ask / deny 三档行为各验一次，与档位一致。
4. 写入超限文本不损坏任何文件。
5. 故意写坏状态文件 → 行为回落且明确提示，而不是按损坏值执行。
6. 卸载后宿主正常、用户文件仍在。
